# Meeting Extractor

Extract meeting content and insights from Microsoft 365 for the Midtown toy chest.

## Status

🚧 **Early stage / placeholder** — This repository is initialized but the implementation is pending.

## Planned Purpose

Extract and process meeting-related content:
- Extract transcripts from Teams meetings
- Pull meeting notes and recordings metadata
- Extract action items and decisions from meeting content
- Generate meeting summaries and follow-up tasks
- Integrate with [todo](https://github.com/Midtown-Technology-Group/todo) for action item tracking

- [calendar-glance](https://github.com/Midtown-Technology-Group/calendar-glance) — View calendar agenda

- [mail-triage](https://github.com/Midtown-Technology-Group/mail-triage) — Follow up on meeting-related mail
